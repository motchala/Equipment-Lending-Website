# Faculty Code: Simple Guide

## What is this?
Students do not have accounts. To borrow equipment or reserve a room, a student needs a **code from a faculty member**. The code is how the faculty gives their permission, and every request made with it is linked to that faculty.

## How it works

1. **Faculty generates a code.** On the faculty dashboard, the **Student Access Code** card has a **Generate New Code** button. The code looks like `abc-123-xy4`.
2. **Faculty gives the code to the student**, using the **Copy** button.
3. **Student enters the code** on the Student Portal, together with their name and course.
4. **Student borrows equipment or reserves a room.** One code works for both.
5. **The code is used up.** The faculty's card changes to show who used it and when, and the faculty gets a toast message. The faculty can then generate a new code for the next student.

## Rules

- A code can be used **once**. A used code is rejected with "This code has already been used."
- A faculty has **one active code at a time**. Generating a new code replaces the old unused one.
- A code **does not expire by time**. It stays valid until it is used or replaced.
- Borrowing **several items in one go** still counts as one use. The code stays valid until the last item is submitted.
- If a request is **turned down on the spot** (for example, the time or equipment is not available), the code is **not used up**, so the student can fix the problem and try again.
- If the faculty has an **overdue item**, students cannot borrow with their code until it is returned, and the faculty cannot make a new code while that setting is on in Settings.
- The code uses letters and numbers that are hard to mix up. It never contains `0`, `1`, `i`, `l` or `o`.

## What the faculty sees

- The faculty card updates by itself every **5 seconds**, so there is no need to refresh.
- The faculty gets an **email** when a student starts using their code, and another when the request is submitted, with its result (approved, pending or declined). Emails follow the faculty's Notification Preferences.
- If the faculty did not give the code to anyone, the first email is the warning that the code may have been shared.

## Quick test

1. Sign in as faculty and press **Generate New Code**. A code appears.
2. Open the Student Portal and enter that code with a name and course.
3. Submit an equipment request or a room reservation.
4. Back on the faculty dashboard, the card shows the student's name and the time the code was used.
5. Try the same code again. It is rejected.
